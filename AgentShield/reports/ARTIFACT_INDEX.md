## 1. Executive Summary

This index provides end-to-end provenance and traceability for every empirical metric, benchmark dataset, machine learning checkpoint, figure, and report produced by the AgentShield project. Every reported claim is directly grounded in an immutable, verified on-disk artifact.

> [!NOTE]
> All private development credentials, local OAuth tokens, and environment secrets (`.env`, `credentials.json`, `token.json`) are strictly excluded from public artifacts and version control.

## 5. Artifact Verification Protocol

To verify that on-disk artifacts match reported checksums and load cleanly, execute:

```bash
python -c "
import os, json
results = ['eval_vulnerable_baseline.json', 'eval_guard_only.json', 'eval_policy_only.json', 'eval_combined_agentshield.json']
for r in results:
    p = os.path.join('AgentShield', 'results', r)
    assert os.path.exists(p), f'Missing artifact: {p}'
    with open(p) as f:
        d = json.load(f)
    print(f'[+] Verified {r}: {len(d.get(\"episodes\", []))} evaluated episodes')
print('[+] All core evaluation artifacts verified.')
"
```
